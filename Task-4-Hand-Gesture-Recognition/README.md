# ✋ Hand Gesture Recognition

## 📌 Overview

This project was completed as part of my **Machine Learning Internship at Prodigy InfoTech**.

The objective of this task is to develop a **hand gesture recognition model** capable of identifying and classifying different hand gestures from image data.

## 🎯 Objectives

* Work with image-based hand gesture data
* Preprocess and prepare image data
* Extract useful features for classification
* Train a machine learning model
* Classify different hand gestures
* Explore practical applications of gesture recognition

## 🛠️ Technologies Used

* Python
* Jupyter Notebook
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

## 🤖 Machine Learning

The project applies machine learning techniques to recognize different hand gestures from image data.

The trained model learns patterns from the available gesture images and uses these patterns to classify new inputs.

## 💡 Key Learning

This task provided practical experience with **image processing, feature preparation, machine learning classification, and computer vision applications**.
