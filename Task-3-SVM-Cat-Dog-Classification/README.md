# 🐱🐶 Cat and Dog Image Classification using SVM

## 📌 Overview

This project was completed as part of my **Machine Learning Internship at Prodigy InfoTech**.

The objective of this task is to build a **Support Vector Machine (SVM)** model to classify images of cats and dogs using a dataset obtained from Kaggle.

## 🎯 Objectives

* Work with an image classification dataset
* Prepare image data for machine learning
* Extract suitable features from images
* Train an SVM classification model
* Evaluate classification performance
* Generate predictions for unseen images

## 🛠️ Technologies Used

* Python
* Jupyter Notebook
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

## 🤖 Machine Learning Algorithm

**Support Vector Machine (SVM)**

SVM is a supervised machine learning algorithm commonly used for classification tasks. It finds an optimal decision boundary that separates different classes in the feature space.

In this project, SVM is used to distinguish between **cat and dog images**.
