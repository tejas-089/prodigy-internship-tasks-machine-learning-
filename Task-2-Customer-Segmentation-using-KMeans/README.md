# 🛍️ Customer Segmentation using K-Means Clustering

## 📌 Overview

This project was completed as part of my **Machine Learning Internship at Prodigy InfoTech**.

The objective of this task is to use **K-Means Clustering** to segment customers of a retail store based on their purchasing behavior and identify meaningful customer groups.

## 🎯 Objectives

* Explore customer purchasing data
* Analyze relationships between customer attributes
* Apply the K-Means clustering algorithm
* Identify distinct customer segments
* Visualize the resulting clusters
* Gain practical experience with unsupervised machine learning

## 🛠️ Technologies Used

* Python
* Jupyter Notebook
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

## 🤖 Machine Learning Algorithm

**K-Means Clustering**

K-Means is an unsupervised machine learning algorithm that groups data points into a predefined number of clusters based on their similarity.

In this project, customer data is analyzed to identify groups of customers with similar purchasing characteristics.
