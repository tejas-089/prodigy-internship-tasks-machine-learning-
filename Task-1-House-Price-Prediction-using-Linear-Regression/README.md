# 🏠 House Price Prediction using Linear Regression

## 📌 Overview

This project was completed as part of my **Machine Learning Internship at Prodigy InfoTech**.

The objective of this task is to build a **Linear Regression model** that predicts house prices based on relevant features from a housing dataset.

## 🎯 Objectives

* Understand and preprocess housing data
* Perform exploratory data analysis
* Select relevant features for prediction
* Train a Linear Regression model
* Evaluate the model's performance
* Generate house price predictions

## 🛠️ Technologies Used

* Python
* Jupyter Notebook
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

## 🤖 Machine Learning Algorithm

**Linear Regression**

Linear Regression is a supervised machine learning algorithm used to model the relationship between input features and a continuous target variable.

In this project, the model learns the relationship between housing features and house prices to make predictions for new data.
